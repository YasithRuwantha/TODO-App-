# 🧩 Task Board Frontend

This is the frontend of a Trello-style task management application built using React.

---

## 🚀 Tech Stack

- React.js
- Axios
- Tailwind CSS
- @hello-pangea/dnd (Drag & Drop)

---

## ⚙️ Setup Instructions

1. Navigate to frontend folder

```bash
cd frontend

2. Install dependencies:
npm install

3. Start the application:
npm start

The app will run at:
http://localhost:3000


Make sure the backend is running before starting the frontend.
